About This Project

        


        
        

          

            
School Project

            

              This web application was developed as a collaborative school project by our team. The primary goal was to demonstrate modern UI design, asynchronous API integration, and persistent CRUD (Create, Read, Update, Delete) operations using browser storage.

Technical Documentation

            
Technologies, libraries, and APIs utilized in this application.

          

          

            
    
              
  • 
                
    
                  
                
    
                
    
                  
    HTML, CSS & Vanilla JS
    
                  
    Built entirely without heavy JavaScript frameworks (like React or Angular) to demonstrate core DOM manipulation, event delegation, and fundamental web technologies.
    
                
    
              
    • 
              
  • 
                
    
                  
                
    
                
    
                  
    Tailwind CSS (CDN)
    
                  
    Used for rapid UI development and styling. Leveraged utilities for flexbox, grids, responsive breakpoints, and glassmorphism (backdrop-blur) to create the modern dual-theme directly in the HTML.
    
                
    
              
    • 
              
  • 
                
    
                  
                
    
                
    
                  
    Lyrics.ovh API
    
                  
    A public, free-to-use REST API for querying artists, fetching real-time song suggestions, and retrieving full lyric text dynamically. Implemented using standard asynchronous fetch() requests.
    
                
    
              
    • 
              
  • 
                
    
                  
                
    
                
    
                  
    LocalStorage API
    
                  
    Provides persistent data storage directly in the browser. Used to securely save the "Vault" collection (lyrics and personal notes) and the user's theme preference.
